# GOwalk (MouseWalk)

Небольшая утилита на Go, которая имитирует лёгкое движение мыши, отражающееся от краёв экрана, — чтобы система не уходила в сон, не гасила экран и не помечала тебя как «неактивен» в Slack/Teams и подобных.

Как только реальный курсор двигается сам по себе (пользователь взял мышь), программа это замечает и останавливается — управлять курсором принудительно она не пытается.

## Статус проекта

Проект в раннем состоянии: собран и протестирован только под **macOS на Apple Silicon (arm64)**. Единственный способ упаковки — скрипт [scripts/build-macos-app.sh](scripts/build-macos-app.sh), готовых установщиков и релизов пока нет.

## Требования

- macOS на Apple Silicon (M1/M2/M3/…)
- [Go](https://go.dev/) 1.26+
- Xcode Command Line Tools (нужны для сборки cgo-зависимостей `robotgo`/`gohook`):
  ```bash
  xcode-select --install
  ```
- Разрешение **System Settings → Privacy & Security → Accessibility** для собранного приложения — без него macOS молча не даёт программе управлять курсором.

## Сборка

```bash
git clone https://github.com/larigoris/go-mouse.git
cd go-mouse
./scripts/build-macos-app.sh
```

Скрипт соберёт бинарник под архитектуру машины, на которой запущен, соберёт иконку и положит результат в:

- `dist/GOwalk.app` — приложение-бандл (запускается двойным кликом)
- `build/GOwalk` — отдельный бинарник (запускается из терминала)

Опционально можно задать имя приложения и папку вывода:

```bash
./scripts/build-macos-app.sh MyMouseWalk /path/to/output
```

## Запуск

При первом запуске macOS запросит разрешение Accessibility — его нужно выдать в System Settings → Privacy & Security → Accessibility, иначе курсор двигаться не будет.

```bash
open dist/GOwalk.app
# или
./build/GOwalk
```

## Журналы

Каждый запуск пишет отдельный файл журнала: время старта, раскладка мониторов,
исходная позиция курсора, сводка о движении каждые 5 секунд и — главное —
причина остановки. Ошибки C-библиотек (`robotgo`/`gohook`) тоже попадают туда,
поэтому при запуске из Finder диагностика не теряется.

| ОС | Каталог |
|---|---|
| macOS | `~/Library/Logs/GOwalk/` |
| Linux | `$XDG_STATE_HOME/GOwalk/logs` (или `~/.local/state/GOwalk/logs`) |
| Windows | `%LOCALAPPDATA%\GOwalk\Logs` |

Хранятся 10 последних файлов, старые удаляются автоматически.

Узнать каталог и сразу открыть его:

```bash
./build/GOwalk -logs            # напечатать путь
open "$(./build/GOwalk -logs)"  # открыть в Finder (macOS)
```

На macOS каталог `~/Library` скрыт флагом `hidden`, поэтому в Finder его не
видно. Кроме команды выше, туда можно попасть через **Переход → Библиотека**
(удерживая **Option**), сочетанием **Cmd+Shift+G**, или открыть журналы
в **Console.app** — это штатный просмотрщик для `~/Library/Logs`.
Чтобы показать `~/Library` в Finder навсегда: `chflags nohidden ~/Library`.

Переменные окружения:

- `GOWALK_LOG_DIR` — свой каталог журналов вместо каталога по умолчанию;
- `GOWALK_VERBOSE=1` — отладочные записи (отражения от краёв экрана).

Приложение, запущенное из Finder, переменные окружения из `~/.zshrc` **не
наследует** — для `.app` их задают через `launchctl setenv`, ключ `LSEnvironment`
в `Info.plist`, либо `open --env`.

## Известные проблемы

- **Второй монитор.** Границы отражения курсора сейчас считаются только по основному дисплею (`CGMainDisplayID`). Если курсор находится на втором мониторе, границы движения будут неверными, и поведение — некорректным (курсор может застревать или программа завершаться раньше времени). Работа с несколькими мониторами — по факту не поддерживается.
- Подпись сборки — ad-hoc (без Developer ID), поэтому Gatekeeper может ругаться при первом запуске, а разрешение Accessibility способно слетать после пересборки.
- Разрешение Accessibility выдаётся **отдельно** для запуска из терминала и для `.app`: при запуске из терминала macOS приписывает права самому терминалу, а бандлу нужен собственный грант. Без него программа завершается примерно за 40 мс — причина будет записана в журнал.
